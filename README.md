# Broken Unoptimized Lab

This repository is intentionally messy, repetitive, and poorly structured for bug-fixing practice.

## Layout
- `app.py` - main Python entrypoint with bad patterns
- `src/services/data_service.py` - inefficient data handling
- `src/utils/helpers.py` - duplicated helper logic
- `web/index.html` and `web/static/style.css` - messy frontend files
- `scripts/run.js` - sloppy JS script

## Notes
- The code is intentionally unoptimized.
- Some logic is wrong on purpose.
- File organization is shallow and inconsistent.
